# Long Video — 4 Output Modes

4 level detail output. Default: **Full Script + Prod Notes**.

## 1. Bullet Only

**Generate:**
- Key points per chapter (3-5 bullets)
- YouTube chapters (timestamps + judul)
- Rekomendasi judul (SEO)
- YouTube tags

**Skip:**
- Full spoken words
- Production notes
- Headline overlay
- B-roll keywords
- Video description panjang

**Word count**: 300-500 kata
**Best for**: Creator experienced yang improv dari bullet points.

## 2. Bullet + Prod Notes

**Generate:**
- Key points per chapter + production direction
- YouTube chapters (timestamps + judul + deskripsi)
- B-roll keywords per chapter
- Rekomendasi judul (SEO)
- YouTube tags
- Video description (short)

**Skip:**
- Full spoken words (bullet only)
- Headline overlay text

**Word count**: 500-800 kata
**Best for**: Creator + editor team.

## 3. Full Script

**Generate:**
- Complete spoken words, line-by-line
- YouTube chapters (timestamps + judul + deskripsi)
- Rekomendasi judul (SEO)
- YouTube tags
- Video description (full)
- Rekomendasi konten selanjutnya

**Skip:**
- Production notes
- B-roll keywords
- Headline overlay text

**Word count**: 1,500-3,000+ kata
**Best for**: Solo creator reading teleprompter.

## 4. Full Script + Prod Notes — DEFAULT

**Generate:**
- ALL — complete spoken words + production notes
- YouTube chapters (timestamps + judul + deskripsi)
- Video description (full)
- YouTube tags
- Rekomendasi judul (SEO)
- B-roll keywords per sisipan
- Rekomendasi konten selanjutnya

**Word count**: 2,000-4,000+ kata
**Best for**: Full production team.

## Quick Decision Tree

```
Shoot + edit sendiri, suka improv?     → Bullet Only
Punya editor, suka improv?             → Bullet + Prod Notes
Baca teleprompter, edit sendiri?       → Full Script
Full team?                              → Full Script + Prod Notes (default)
Ga yakin?                               → Full Script + Prod Notes (default)
```

## Short Form Extraction — 2 Metode dari Long Form

Dua cara menarik short-form content dari materi long-form, dengan efektivitas berbeda:

**Metode 1 — Tandai saat scripting (lebih efektif):**
Pada fase scripting, langsung tandai bagian mana yang jadi Short 1, Short 2, Short 3. Hook short form sudah dirancang dari awal → hasilnya lebih tajam dan self-contained.

**Metode 2 — Potong dari hasil shooting (lebih mudah):**
Shoot long form apa adanya, tim editor yang mencari dan memotong bagian yang worth it. Hasilnya tetap bisa work, tapi tidak se-work Metode 1.

**Prinsip:** short form yang didesain sejak scripting selalu lebih kuat dari short form yang dipotong dari long form yang tidak dirancang untuk itu.

**Tips untuk niche visual (seni, crafts):** jangan potong di tengah proses — gunakan timelapse keseluruhan proses + overlay teks tips langkah per langkah. Mid-process cut terasa tanggung dan tidak satisfying.
