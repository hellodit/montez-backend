# Long-Form Emotional Arc — Multi-Chapter Emotion Mapping

Reference file untuk skill `write-script-longvid`. Engine emosi di balik video panjang (8-20 menit).
Nama hormon TIDAK ditulis di output script — ini panduan internal untuk bikin arc yang engaging.

Lihat juga: `neuroscience-video-emotion.md` (4 hormon dasar), `storytelling-framework.md` (HEIA + Foreshadowing)

## Perbedaan Arc: Short-Form vs Long-Form

**Short-form (15-60 detik):**
- 1 arc: Hook → Build → Climax → Release
- Emosi naik linear, 1 puncak
- Ga ada waktu untuk recovery/variasi

**Long-form (8-20 menit):**
- Multiple arcs: setiap chapter punya mini-arc sendiri
- Macro-arc (keseluruhan video) + micro-arcs (per chapter)
- Ada "valleys" — viewer butuh emotional rest sebelum puncak berikutnya
- Re-hooks di valley points untuk recapture attention

## Macro-Arc: 6-Act Emotional Structure

Ini template emosi keseluruhan video. Applicable ke semua style.

```
TENSION
  ↑
  │         ╱╲          ╱╲
  │        ╱  ╲   ╱╲  ╱  ╲        ╱╲
  │   ╱╲  ╱    ╲ ╱  ╲╱    ╲      ╱  ╲
  │  ╱  ╲╱      ╲         ╲    ╱    ╲
  │ ╱                       ╲  ╱      ╲
  │╱                         ╲╱        ╲___
  └────────────────────────────────────────→ TIME
  HOOK  BUILD  STORIES  TWIST  ANSWER  CLOSE
  Ch1   Ch2    Ch3      Ch4    Ch5     Ch6
```

| Act | Chapter | Emosi Dominan | Fungsi | Durasi % |
|---|---|---|---|---|
| 1. HOOK | Ch1 | Cortisol → Dopamine | Grab + plant foreshadow | 10-12% |
| 2. BUILD | Ch2 | Cortisol (escalating) | Data/context, build tension | 15-20% |
| 3. STORIES | Ch3 | Cortisol → Oxytocin | Empathy via real stories | 25-30% |
| 4. TWIST | Ch4 | Dopamine (surprise) | Counter-argument, reframe | 15-20% |
| 5. ANSWER | Ch5 | Endorphin (empowerment) | Payoff foreshadow + action steps | 15-18% |
| 6. CLOSE | Ch6 | Dopamine (next video) | CTA + tease next content | 5-8% |

### Valley Points (Emotional Rest)
- **Between Ch2 → Ch3:** Tension built, needs brief pause before stories
- **Between Ch4 → Ch5:** After twist surprise, pause to let it sink in
- Valley = moment untuk re-hook ("dan ini baru awalnya...")

## Micro-Arc: Per-Chapter Emotion Template

Setiap chapter punya arc kecil sendiri:

```
CHAPTER MICRO-ARC:
  Setup (10%) → Build (40%) → Peak (30%) → Bridge (20%)
```

- **Setup:** Context untuk chapter ini, connect ke chapter sebelumnya
- **Build:** Escalate tension/interest dalam chapter
- **Peak:** Moment terkuat di chapter (data shock, story climax, reveal)
- **Bridge:** Transition ke chapter berikutnya, sering berisi re-hook

## Arc per Video Style

### Storytelling
```
Ch1: SHOCK (cortisol) — dramatic opening
Ch2: CONTEXT (cortisol build) — data/background
Ch3: EMPATHY (oxytocin) — real stories, relatable
Ch4: TWIST (dopamine) — unexpected perspective
Ch5: RESOLUTION (endorphin) — answer + empowerment
Ch6: CALL (dopamine) — what's next
```
Paling emotionally varied. Butuh strong narrative thread.

### Talk-to-Camera
```
Ch1: PROVOKE (cortisol) — bold statement
Ch2: EVIDENCE (cortisol + dopamine) — backing up claim
Ch3: NUANCE (oxytocin) — personal experience, "gue juga ngalamin"
Ch4: REFRAME (dopamine) — shift perspective
Ch5: ACTION (endorphin) — concrete steps
Ch6: INVITE (oxytocin) — build relationship, subscribe
```
Lebih personal. Oxytocin lebih dominan karena face-to-face connection.

### Narrated/Documentary
```
Ch1: MYSTERY (dopamine) — open question/scene
Ch2: INVESTIGATION (cortisol) — deep dive data
Ch3: DISCOVERY (dopamine + cortisol) — findings revealed
Ch4: IMPLICATIONS (cortisol) — what this means
Ch5: CONCLUSION (endorphin) — answer + bigger picture
Ch6: TEASE (dopamine) — next episode/topic
```
Dopamine-heavy. Curiosity-driven dari awal sampai akhir.

### Listicle
```
Ch1: HOOK (cortisol) — "X things about Y"
Ch2-5: ITEMS (cortisol → dopamine per item) — escalating, best saved for last
Ch6: CLOSE (endorphin) — summary + CTA
```
Paling straightforward. Setiap item = mini-arc. Items harus ESCALATE (yang terakhir paling impactful).

### Hybrid (Campuran)
```
Ch1: HOOK (cortisol) — face cam, bold statement
Ch2: CONTEXT (cortisol) — switch to narration + footage
Ch3: DEEP DIVE (dopamine) — back to face cam + data
Ch4: STORIES (oxytocin) — narrated case studies
Ch5: ANSWER (endorphin) — face cam, personal take + action
Ch6: CLOSE (dopamine) — face cam CTA
```
Variasi delivery keeps viewer engaged. Switch between modes prevents fatigue.

## Foreshadowing Integration Points

Foreshadowing paling efektif di:

| Titik | Kapan | Contoh |
|---|---|---|
| Hook (Ch1) | Detik 30-60 | "Tapi ada 1 hal yang semua orang miss..." |
| End of Build (Ch2) | Setelah data shock | "Data ini baru setengah cerita..." |
| Mid-Stories (Ch3) | Setelah case study | "Tapi ada pattern yang connect semua cerita ini..." |
| Pre-Answer (Ch4 end) | Sebelum resolution | "Dan jawabannya ternyata udah ada dari awal..." |

Rules:
- **Max 2-3 foreshadow arcs per video** — lebih dari itu confusing
- **Setiap foreshadow HARUS punya payoff** — broken promise = viewer trust lost
- **Payoff distance:** minimum 3 menit, maximum seluruh video
- **Payoff harus SEBAIK promise-nya** — golden rule dari storytelling-framework.md

## Data Neuroscience Terbaru (2025-2026)

- **Cortisol + Oxytocin combo** = attention lock terkuat. Compelling narrative trigger cortisol (suspense → focus naik) dan oxytocin (empathy → trust naik) secara bersamaan (Paul Zak, PMC/NIH)
- **Cara cerita diceritain mengubah cara otak menyimpan** — vivid sensory detail vs thoughtful reflection → encode di neural pathways yang berbeda (Journal of Neuroscience, 2025). Implikasi: mix "show" (visual detail) dan "tell" (reflection) di script
- **Brain synchronization** — storytelling bikin otak penonton sync dengan otak storyteller. Ini kenapa face-cam storytelling lebih engaging dari voiceover (NeuroLeadership Institute)
- **Attention span 2026: 7.9 detik** (University of Amsterdam). Long-form storytelling survive **hanya kalau** paired dengan engaging visuals + hooks early on
- **Memory encoding** — stories 22x lebih memorable dari data saja (Zak, 2015). Tapi cara encoding beda: sensory stories → episodic memory (vivid recall), reflective stories → semantic memory (meaning retention)
