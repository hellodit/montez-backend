# Swipe Psychology Engine

Internal engine yang guide copy per slide. **JANGAN output nama teknik ke user** — implement secara natural.

## Core Rules (non-negotiable)

- **ALWAYS:** setiap slide punya swipe hook (cliffhanger / tease / question) — kecuali slide CTA terakhir

## 6 Teknik Swipe

| Teknik | Effect | Implementation |
|---|---|---|
| **Cliffhanger** | Zeigarnik Effect — incomplete = must swipe | Setiap slide end incomplete |
| **Open Loop** | Cognitive tension | Start thought slide N, finish slide N+1 |
| **Escalation** | Dopamine ramp | Each slide more impactful; last = peak |
| **Endowed Progress** | Commitment bias | After 5 swipes, compelled to finish |
| **Pattern Interrupt** | Attention reset | Slide 5-6 beda visual/content rhythm |
| **Carousel Loop** | Infinite scroll | Last slide visual → back to Slide 1 |

## Swipe Rules (Non-Negotiable)

```
SETIAP slide HARUS punya salah satu:
- Open loop yang belum ditutup
- Angka/list yang belum lengkap
- Pertanyaan yang belum dijawab
- "Tapi..." / "Kecuali..." / "Yang paling..."

KECUALI slide terakhir (CTA) — satu-satunya slide yang boleh "selesai"
```

## Emotional Beat Map per Format

Target emosi per slide position. Internal compass — **JANGAN tulis nama hormon di output**.

### Edukasi / Listicle (10 slides)

```
Slide 1 (Cover):    Cortisol/Dopamine   — stop scroll
Slide 2 (2nd Hook): Oxytocin            — empathy / proof / "ini gue"
Slide 3-4:          Dopamine            — content, escalating
Slide 5 (Interrupt): Pattern break      — stat / visual reset
Slide 6-7:          Dopamine peak       — reveal / climax
Slide 8:            Oxytocin            — insider / trust
Slide 9:            Endorphin           — aha / payoff
Slide 10 (CTA):     Endorphin           — action
```

### Jualan (10 slides)

```
Slide 1:   Cortisol     — pain hook
Slide 2:   Cortisol     — agitate
Slide 3:   Oxytocin     — "gue juga pernah"
Slide 4-5: Dopamine     — solution tease
Slide 6-7: Dopamine     — proof / data / testimonial
Slide 8-9: Endorphin    — transformation / result
Slide 10:  Endorphin    — CTA + anxiety removal
```

### Storytelling (10 slides)

```
Slide 1:   Cortisol/Dopamine — hook + foreshadow
Slide 2-3: Oxytocin          — setup, relatable
Slide 4-5: Cortisol          — conflict, tension
Slide 6-7: Cortisol peak     — darkest moment
Slide 8:   Dopamine          — twist / turning point
Slide 9:   Endorphin         — resolution
Slide 10:  Endorphin         — CTA
```

## Application Notes

- Emotional beat = target behind copy, bukan label eksplisit
- Consumer wrapper boleh label emosi kalau target audience-nya teknis; default: natural
- Pattern interrupt slide ideal di mid-carousel (slide 5-6 dari 10)

## Cover = 70% Effort Rule

Kerahkan **70% kreativitas** untuk cover (Slide 1). Audiens punya **3 detik** untuk memutuskan klik atau skip (Facebook data). Kalau cover gagal di 3 detik ini, Slide 2–10 tidak pernah dilihat — seluruh nilai konten hilang.

Journey yang dimulai dari cover berhasil: **cover menarik → klik & scroll → baca habis → suka → profile visit → follow**. Satu cover yang gagal memutus seluruh rantai ini di titik pertama.

Urutan mata membaca cover (Instagram/carousel): **warna kontras dulu → gambar → teks terakhir**. Optimalkan warna dan gambar sebelum headline — orang belum kenal lo cenderung skip teks.
