# Long Video — 5 Styles

## Core Rules (non-negotiable)

- **ALWAYS:** foreshadowing di menit pertama — preview payoff/climax biar audience stay
- **ALWAYS:** re-hook di 50% durasi (tension reset / new angle / reveal)

## 1. Talk-to-Camera (Ngomong ke Kamera)

- **Structure**: Speaker langsung, personal delivery, minimal B-roll
- **Best for**: Personal brand, opinion, expertise sharing
- **Durasi**: 8-12 menit
- **Reference creators**: Ali Abdaal, GaryVee

**Emotional Arc:**
```
PROVOKE (cortisol) → EVIDENCE (cortisol+dopamine) → NUANCE (oxytocin) →
REFRAME (dopamine) → ACTION (endorphin) → INVITE (oxytocin)
```

**Production:**
- Face cam 70%+ screen time
- B-roll sparingly (emphasis only)
- On-screen text untuk key points
- Music subtle

## 2. Narasi + Footage (Documentary)

- **Structure**: Voiceover + footage/motion graphics, high production
- **Best for**: Explainer, deep dive, investigasi, educational
- **Durasi**: 12-20 menit
- **Reference creators**: Kurzgesagt, Wendover Productions

**Emotional Arc:**
```
MYSTERY (dopamine) → INVESTIGATION (cortisol) → DISCOVERY (dopamine+cortisol) →
IMPLICATIONS (cortisol) → CONCLUSION (endorphin) → TEASE (dopamine)
```

**Production:**
- Voiceover 100% (no/minimal face cam)
- Heavy B-roll + motion graphics
- Sound design important (SFX, ambient)
- Pacing: measured, authoritative

## 3. Listicle

- **Structure**: Numbered items dengan elaboration, clear sections
- **Best for**: Rankings, comparisons, "X terbaik/terburuk", how-to lists
- **Durasi**: 8-15 menit
- **Reference creators**: MrBeast, WatchMojo

**Emotional Arc:**
```
HOOK (cortisol) → ITEMS [escalating] (cortisol→dopamine) →
BEST ITEM [saved for last] (dopamine peak) → CLOSE (endorphin)
```

**Production:**
- Clear numbering (on-screen + verbal)
- Each item = mini-segment with own arc
- Items HARUS escalate — last = most impactful
- Transition effects between items
- Number Anchor re-hook works best

## 4. Storytelling

- **Structure**: Setup → conflict → twist → resolution
- **Best for**: Case studies, biographies, "bagaimana X terjadi", investigative
- **Durasi**: 12-18 menit
- **Reference creators**: Johnny Harris, ColdFusion

**Emotional Arc:**
```
SHOCK (cortisol) → CONTEXT (cortisol build) → EMPATHY (oxytocin) →
TWIST (dopamine) → RESOLUTION (endorphin) → CALL (dopamine)
```

**Production:**
- Strong narrative thread — scene connects
- Foreshadowing paling efektif di style ini
- Mix face cam + narration + footage
- Character-driven (bukan topic-driven)
- Story Cliff re-hook works best

## 5. Campuran (Hybrid) — DEFAULT

- **Structure**: Mix face cam + B-roll + narasi. Paling flexible.
- **Best for**: Tutorial + opinion, review + analysis, complex topics
- **Durasi**: 10-16 menit
- **Reference creators**: MKBHD, Fireship

**Emotional Arc:**
```
HOOK (cortisol) → CONTEXT (narrated) → DEEP DIVE (face cam) →
STORIES (narrated, oxytocin) → ANSWER (face cam) → CLOSE (dopamine)
```

**Production:**
- Switch delivery mode tiap 2-3 menit (face cam ↔ narration ↔ screen)
- Visual variasi = anti-fatigue
- Default untuk topik multi-angle

## Auto-Recommend Decision Tree

```
Topik opini/expertise?        → Talk-to-Camera
Topik explainer/data-heavy?   → Narasi + Footage
Topik ranking/comparison?     → Listicle
Topik cerita/case study?      → Storytelling
Mixed / uncertain?            → Campuran (default, safest)
```
